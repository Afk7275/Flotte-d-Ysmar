# ⚓ Flotte d'Ysmar

**A naval simulation and tactical strategy game set in the Mediterranean Sea.**

Flotte d'Ysmar puts you in command of a naval force operating in a dynamic Mediterranean environment. Navigate your ships, manage missions, communicate with other vessels, and make tactical decisions as you lead your fleet through its campaign.

## 🎮 Features

- **Naval operations** — Control your ships and navigate through the Mediterranean.
- **Campaign system** — Complete missions and progress through a broader operational storyline.
- **Multiple vessel types** — Command a fleet featuring different surface ships and a submarine.
- **Tactical combat** — Track targets, manage weapons, and make decisions during engagements.
- **Navigation systems** — Use the radar, tactical map, compass, and helm controls.
- **Fleet communications** — Exchange messages with other ships and characters through an in-game communication system.
- **Port management** — Access port facilities and manage aspects of your naval operations.
- **Ship systems** — Monitor vessel status and respond to operational incidents.
- **Immersive interface** — A naval command interface designed to make you feel like you're operating a real fleet.

## 🌊 Setting

The game takes place in the Mediterranean Sea, where naval operations, missions, and communications shape your experience.

You are responsible for managing your vessel and carrying out your assigned objectives while reacting to events as they unfold.

## 🛠️ Getting Started

The game is currently distributed as an HTML file.

### Run locally

1. Download or clone this repository.
2. Locate `Flotte d'Ysmar.html`.
3. Open the file in a modern web browser.
4. Start a mission and explore the available systems.

No traditional installation should be necessary for the standalone HTML version. Additional requirements may apply if the project uses external resources.
